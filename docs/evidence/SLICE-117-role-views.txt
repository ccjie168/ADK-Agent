SLICE-117 角色视图与能力清单

环境
- Windows 11 Pro, Python 3.14 venv, FastAPI TestClient
- 浏览器: headless Edge via DevTools Protocol
- 三个控制台同源代码，--allow-unauthenticated，分别给 --role operator、viewer、publisher
- 端口 8092 operator、8093 viewer、8094 publisher

一、反例红（实现前）

  此时页面没有 data-capability。

三、浏览器
operator (8092)
  tabs: Chat, Runs, Sessions, Approvals, Grants, Plans, Registry, Connectors, Peers, Policy
  panels: chat, registry, connectors, peers, runs, sessions, approvals, grants, plans, policy
  buttons: approve=true, grant_approve=true, open_chat=false, grant_request=false,
           connector_register=false, peer_register=false, save_policy=false
  结论: 能看运营、构建与治理，能审批；管理类写按钮与 Open chat 不出现。

viewer (8093)
  tabs: Chat, Runs, Sessions, Plans
  panels: chat, runs, sessions, plans
  buttons: 全部 false
  深链 http://127.0.0.1:8093/#policy 加载后 active 仍是 Chat，Policy 未打开
  结论: 只有基础视图，深链不会绕过能力检查。

publisher (8094)
  tabs: Chat, Runs, Sessions, Grants, Plans, Registry, Tools
  panels: chat, registry, tools, runs, sessions, grants, plans
  buttons: grant_request=true, open_chat=true, grant_approve=false,
           approve=false, save_policy=false
  结论: 能发布与申请工具授权，不能审批，不能管理连接器或 peer。
