SLICE-119 运行详情下钻

环境
- Windows 11 Pro, Python 3.14 venv, FastAPI TestClient
- 浏览器: headless Edge via DevTools Protocol
- 控制台 127.0.0.1:8102，--audit-file 指向种入的审计链
- 种子: 一条 agent 运行 trace 与一条 orchestration 计划 trace，含拒绝态、出站标记、策略版本与注入文本

一、反例红（实现前）
  $ ./.venv/Scripts/python.exe -m pytest tests/test_console_trace_detail.py -q
    3 failed, 1 passed
  test_node_carries_audit_fields 断言失败。
  test_node_keeps_null_fields 在 approver 上 KeyError。

  不过原文用例在红态下本就通过，因为缺字段时自然没有 prompt、completion、input、args 这些键。
