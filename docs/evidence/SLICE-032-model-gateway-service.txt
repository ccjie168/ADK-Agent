------------

审计写 audit.jsonl。

{"action":"model.call","target":"fake:m","tokens":7,"cost_usd":0.0001,"status":"ok",...}

说明
----
- ModelGatewayRequest 是 invocation + request + policy，响应复用 ModelResponse。
- 服务只有 /healthz 开放。/v1/complete 需要 bearer token。
- 非回环建应用无 token 抛 ValueError。
- 403 只返回 model_denied，502 只返回 model_call_failed，不回显 provider 异常。
- HttpModelGateway 实现 ModelGateway 端口，token 逐请求带上，可注入客户端。
- JsonlAuditSink 每个事件一行，追加并 fsync。
- CLI serve-model-gateway 支持 litellm 和 vllm，可选 audit-file。
- model_gateway_request.schema.json 已生成。cli.md 已更新。
- ADR-0004 记录拆分顺序和形态，状态 Proposed。

已知边界
--------
- 服务信任调用方送来的 policy，per-caller 权威要等身份映射。
- JSONL 审计单进程，没有轮转和集中投递。
- 没有请求大小上限、速率限制、重试和熔断。
- GatewayLlm 还没切换到 HttpModelGateway。这一刀提供端口和服务。
- 工具网关拆分未开始。
