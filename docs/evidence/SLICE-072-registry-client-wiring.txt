notes
-----
- The first console start failed with `RuntimeError: Event loop is closed` while
  closing the registry client. `_registry_agents` now loads and closes inside
  one event loop; the client docstring records that it belongs to the loop of
  its first call.
- `publish --registry-url` uploads bytes with a single asyncio.run for publish
  plus upload, and closes the client in that loop.
- Console still keeps the local eval report store; report centralization is out
  of scope and `publish --registry-url` rejects --eval-report.
