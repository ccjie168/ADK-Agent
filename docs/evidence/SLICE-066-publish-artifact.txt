== reading ==
- The same project produced the same artifact digest against both stores, so packaging is
  deterministic in practice, not only in the unit test.
- The signature covers the digest; the stored bytes re-hash to it.
- Publishing without --artifact is untouched: no store and no key are required.
- Orphan risk: bytes are stored before the registry write, so a registry conflict can leave an
  unreferenced blob. It is inert and can be garbage-collected later.
