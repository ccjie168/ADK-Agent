日期: 2026-11-25
依据: 用户要求「应用复杂、不知道如何使用」，并要求 HTML 形式
范围: 新增 `docs/guides/console-ui.html`、控制台 `GET /guide`、侧栏入口

二、改动

- `docs/guides/console-ui.html`：单文件手册，内嵌样式，无外部脚本、样式与字体。
  内容：登录方式、导航地图、27 个页面逐页说明（用途/前提/操作/能力）、
  两条完整流程、常见错误对照、手机端说明。
- `src/adk_agent/console.py`：`GET /guide` 返回该文件；`/guide` 加入免鉴权路径；
  文件缺失返回 404 `guide_not_found`。
- `web/src/App.vue`：侧栏「设置」组新增「使用说明」，新标签页打开 `/guide`。
- `docs/contracts/console.md`：新增 `GET /guide` 契约。
- `web/dist/` 重建（侧栏入口变更）。

三、验证

    $ python -m pytest tests/test_console_guide.py -q
    7 passed

实机（控制台 `127.0.0.1:8000`，`--ui vue`）：

    $ curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8000/guide
    200

不带令牌也可访问；返回的 HTML 含「控制台使用手册」。
