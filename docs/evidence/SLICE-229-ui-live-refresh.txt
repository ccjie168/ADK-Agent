SLICE-229 UI 实时刷新（SSE）
日期: 2026-11-22
依据: ADR-0039 第二阶段候选 3（可视化实时化，触发条件已确认）；SSE 用 FastAPI 内置，无新依赖
基线: `19bdcbd`

一、契约

- `docs/contracts/console.md` 补 `GET /api/live` 一节（text/event-stream，每 5 秒一个 tick）。

二、实现

- `console.py` 新增 `GET /api/live`：SSE 流，`async def events() -> AsyncGenerator[str, None]`，
  循环 yield `_sse("tick", {"ts": iso})` 后 `asyncio.sleep(5)`，`request.is_disconnected()` 即停。
- 前端新增 `startLive()`：fetch `/api/live`（带 Authorization header）+ ReadableStream 读 SSE，
  收到 `tick` 就 `loadOverview/loadQuota/loadRag/loadModel/loadSemantics`；读流结束 `setTimeout` 3s 重连。
- `connect()` 登录后调 `startLive()`。
- `scripts/prove_it_works.py`：`check_console_ui`（P13）额外用 `httpx.stream` 断言 `/api/live` 首个
  事件含 `event: tick`。

五、范围与已知缺口

- tick 只推心跳不含业务数据，业务数据仍由各面板按能力查询。
- 「有变化才推」的服务端变更检测后续做；WebSocket 不需要（SSE 够单向推送）。
- 各面板收到 tick 全量刷新，不做增量更新。
