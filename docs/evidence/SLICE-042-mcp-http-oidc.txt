真实 MCP 验证
-------------
本地 JWKS 提供公钥，RS256 token 与配置一致。uvicorn 运行
`build_http_app(MCPServer, auth_token=None, oidc=OidcIdentityProvider(config))`。
客户端用 MCP SDK 的 `streamable_http_client` 调用 `ping` 工具。

valid token: {'result': 'pong'}
no token http: 401 {"error":"unauthorized"}

说明: 真实 MCP 协议和真实签名。认证通过后工具可调用，无 token 被中间件拒绝。
principal 注入没有做，agent 运行仍使用 ADK 的 `mcp_user`，这一项排在 SLICE-043。
实验已确认工具能读到 `ctx.request_context.request.state.principal`，为 043 铺路。
