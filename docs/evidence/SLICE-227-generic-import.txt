依据: ADR-0039 MVP 第 6 项（通用导入：术语表 / agent 定义 / RAG 语料）
基线: `ce0c554`

一、契约

- `docs/contracts/console.md` 补 `POST /api/import/terminology` 与 `POST /api/import/agent` 两节。

二、实现

- `console.py` 新增 `POST /api/import/terminology`：`ConceptScheme` 校验后落到 `terminology` store
  （写 `terminology.import` 审计），结构非法 400 `invalid_scheme`、未配置 404、存储不可用 503。
- 新增 `POST /api/import/agent`：`AgentManifest` 校验后走 `published_from` + `registry.publish`
  （manifest-only，写 `agent.import` 审计），结构非法 400 `invalid_manifest`、跨租户非 admin 403。
- 新增导入面板 `section#import`（kind 选择 + JSON 粘贴框），导航「数据」组加 Import tab，
  `runImport` 前端调用。
- `scripts/prove_it_works.py`：`check_console_ui`（P13）额外断言 `id="import"`。
