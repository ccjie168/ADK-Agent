依据: ADR-0033（Accepted 2026-11-19）决定 3 / slice 4

一、实现

- `AuditEvent` 增加 `model_alias: str | None = None` 与 `fallback_count: int`（`ge=0`，缺省 0）。
- `emit_model_audit` 与 `_complete_once` 增加同名关键字参数并写入事件；`complete` 的 alias 路径把
  alias 与尝试序号（降级次数）透传，直接路径保持缺省。
- 重生成 `audit_event.schema.json` 与 `audit_record.schema.json`（内嵌事件）。
- 实际模型已在事件 `target`（`provider:model`）中记录，本切片补齐 alias 与降级次数。
- 新增 `tests/models/test_model_audit_fields.py` 四个测试。
