## 实现（后绿）

- `console.py`：`GET /api/security`（`ops.read`）返回 audit / keys / policy / scans 四块。
  - `audit.backend` 按审计后端类型判定（file/http/db/memory/none），`records` 为最近 1000 条窗口计数，
    `last_event_at` 取最新事件时间。
  - `?verify=1` 仅文件后端校验：`asyncio.to_thread` + `asyncio.wait_for(10s)`，60 秒结果缓存；
    超时 `verify_timeout`、链断裂 `chain_broken`、非文件后端 `backend_unsupported`。
  - `keys.audit_signing` 只给 active/kids/legacy（`ADK_AUDIT_KEYRING` 或单键 default）；
    `keys.credentials` 给 active key id、按 `secret_key_id` 的计数与 `needs_rewrap` 数。
  - `scans` 读 `--security-report PATH`，解析失败为 null。
  - 审计查询失败、凭据 store 失败、KEK 未配置均返回 null/空对象并记日志，不 500。
- `cli.py`：`console --security-report PATH`。
- 契约：`docs/contracts/console.md` 新增 `GET /api/security`；新增
  `docs/contracts/security_report.schema.json`。
