一、实现

- 新增 `docs/guides/install-and-use.md`：前提、源码安装、模型配置、MCP 与审计/配额、
  控制台、发布与 compose、服务面参数表、凭据（register/控制面/rewrap/吊销、TLS 要求）、
  Docker、升级回滚、排障表。

- 示例密钥一律用占位符或 `${VAR}`，不含真实值。
- 新增 `tests/test_install_guide.py`：章节齐全、每个 `-m adk_agent <cmd>` 都是真实子命令、
  每个命令块里的 flag 都被该命令的 `--help` 接受、凭据章节包含 `ADK_SECRET_KEKS`、
  `credentials rewrap` 与 TLS 要求。

五、第一轮独立验证

结论 DO NOT MERGE。手册里 `compose` 示例用了不存在的 `--param` 且缺必填参数；Docker 示例没有
`ADK_MCP_AUTH_TOKEN`，容器启动即拒绝服务；HTTP/控制台示例没写 token 环境变量；`publish` 示例
多了不存在的 `--artifact-keys`。已逐条修正，并把手册守卫测试从“只校验首个命令词”加强为
“逐个命令块校验每个 flag 都被该命令的 `--help` 接受”，另补章节与凭据环境断言。
