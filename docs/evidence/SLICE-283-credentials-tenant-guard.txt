SLICE-283 凭据接口的调用方租户校验 — 证据
==========================================

日期: 2026-11-25
分支: slice-283-credentials-tenant
依据: PROGRESS 第 16 条既有缺口（`/api/credentials` 对调用方自身非法租户返回 500）

## 反例（先红）

    python -m pytest tests/test_console_credentials_tenant.py -q
    2 failed, 3 passed

失败项：调用方租户为 `bad tenant` 时，`GET /api/credentials` 与
`POST /api/credentials/{id}/disable` 让 `safe_join` 的 `UnsafePath` 逃逸成 500。
显式非法租户、合法租户与 admin 跨租户三条在旧代码上通过，作为回归保护。

## 实现（后绿）

`src/adk_agent/console.py`：

- `GET /api/credentials`：`target = tenant if tenant is not None else caller.tenant`，
  跨租户 403 之后统一校验 `_SAFE_TENANT`，非法返回 400 `unsafe_tenant`（显式空串同样 400，
  保持原有行为）。
- `POST /api/credentials/{credential_id}/disable`：同样先解析 target 再校验，并校验 `credential_id`
  （非法 400 `invalid_credential`），两者都先于存储读取。
- 合法租户与 admin 跨租户路径不变。

    python -m pytest tests/test_console_credentials_tenant.py tests/test_console_credentials.py -q
    21 passed

契约：`docs/contracts/console.md` 的 GET 与 disable 两节写明「解析后的租户」校验与 403/400 顺序。

## 实机验证（8029，`--credentials-dir`，admin）

    GET  /api/credentials                  -> list=200（空清单）
    GET  /api/credentials?tenant=bad%2Fname -> unsafe=400
    POST /api/credentials/crm/disable       -> disable=404（不存在）
    POST /api/credentials/crm/disable?tenant=bad%20tenant -> disable-unsafe=400

调用方自身租户为非法的路径用带自定义 `IdentityProvider` 的 `TestClient` 覆盖（见用例），
实机没有对应 IdP，故不在 HTTP 层重复。

## 独立验证反馈修正

首轮独立验证判 **PASS**（无 B，2 个 S + 2 个 N），已处理：

1. **S-1**：disable 路由只校验租户、不校验 `credential_id`；`POST /api/credentials/bad%20name/disable`
   仍会让 `UnsafePath` 逃逸成 500。现在 `credential_id` 不满足安全字符集返回 400
   `invalid_credential`，契约同步。新增 `test_credentials_disable_rejects_an_unsafe_credential_id`。
2. **N-1**：disable 的显式空 `?tenant=` 由回落调用方租户改为 400 `unsafe_tenant`（契约已写、
   客户端不发空值）。新增 `test_credentials_disable_rejects_an_empty_tenant` 并在证据记录。
3. **S-2（记录）**：disable 无跨租户 403，依赖「`connectors.manage` 仅 admin」的角色策略；
   自定义角色库可授予 manage，届时非 admin 可跨租户停用。契约与实现一致，作为后续策略项记录。
4. **N-2**：8029 实机四行与 TestClient 覆盖互补，未变。

两条新增用例在实现后加入，未参与最初的先红运行（初始红灯仍是 2 失败 / 3 通过）。
