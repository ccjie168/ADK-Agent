日期: 2026-11-22
依据: ADR-0039 MVP 第 1 项（视觉基线先行）

一、契约

无对外接口变更，不改 `docs/contracts/`。设计 token 与卡片 class 是控制台内部视觉骨架。

二、实现

- `src/adk_agent/console.py` `_INDEX_HTML` 的 `<style>`：`:root` 新增设计 token
  （`--radius-sm`/`--radius-lg`/`--shadow-card`/`--shadow-card-hover`/`--space-1` 到 `--space-4`），
  新增 `.metric-grid`（响应式网格）与 `.stat-card`/`.stat-label`/`.stat-value`/`.stat-delta`
  （指标卡片系统），供后续总览页与能力面板复用。
- `scripts/prove_it_works.py`：新增 `check_console_ui`（P13），起真实 console 服务、GET / 断言
  设计 token 与卡片 marker；`CHECKS` 加 `"P13": check_console_ui`。
- `tests/test_console.py`：新增 `test_index_has_design_tokens` 与 `test_index_has_metric_card_system`。
- `tests/test_prove_it_works_selection.py`：`len(selected) == 12` 改为 `len(selected) == len(module.CHECKS)`
  （新增 P13 后 check 数 12 -> 13；用户确认用动态断言而非硬编码数字）。
