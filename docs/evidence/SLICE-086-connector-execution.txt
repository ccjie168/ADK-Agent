notes
-----
- The allowed request reached the loopback server with `Authorization: Bearer
  live-token`, resolved from `ADK_SECRET_CRM_TOKEN` through
  `PrefixedEnvSecretProvider`.
- The redirect response was returned by the server and refused by the adapter;
  httpx does not follow it (`follow_redirects=False`).
- The oversized response was streamed and denied at the byte cap; the server
  saw the connection but not an unbounded read.
- The gateway audit event records `target=crm`, `status=ok`,
  `egress=third_party`.
- `prefixed env` maps every non-alphanumeric character to `_` and uppercases
  the rest, so `secret://crm/token` becomes `ADK_SECRET_CRM_TOKEN`.
