notes
-----
- `build_rate_limiter` reads RATE_LIMIT_URL; unset keeps the in-process
  limiter and leaves existing behavior unchanged.
- The middleware awaits `acheck` when present and falls back to the sync
  `check`, so both limiter types share one middleware.
- Redis failures fall back to a per-process limiter, increment the error
  counter and log one warning per process.
