== file store layout ==
<root>/sha256/<hex>                     bytes, written to a temp name and os.replace'd
Invalid or mismatched digests/sizes leave the root untouched (tests assert no files).

== reading ==
- The store only trusts bytes that hash to the declared digest; a mismatched write is refused
  before any directory is created.
- Digest strings are validated before building a path, so get("..") cannot escape.
- Postgres writes use ON CONFLICT DO NOTHING, so republishing the same artifact is idempotent.
- No CLI or runtime wiring yet; that is SLICE-066/067.
