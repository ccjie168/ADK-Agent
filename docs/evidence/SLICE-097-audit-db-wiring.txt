notes
-----
- Both DB services wrote into the same tenant chain; the console read the row
  the audit service wrote, so write and read paths share one table.
- File mode still produces chained JSONL records and returns the record hash.
- Explicit `--audit-file`/`--audit-url` win over `AUDIT_DATABASE_URL`, matching
  the contract. Review fix: `serve-audit --out` also ignores the env var now;
  before the fix an exported `AUDIT_DATABASE_URL` made `--out` exits 2.
- DB-mode writers sign with the environment keyring. Every writer must share
  the same keyring or `verify-audit --audit-db` fails closed; the contract says
  so.
- The console closes its Postgres audit query on shutdown best-effort. The pool
  is loop-affine and was opened on uvicorn's loop, so a close from a fresh loop
  is suppressed rather than treated as an error.
