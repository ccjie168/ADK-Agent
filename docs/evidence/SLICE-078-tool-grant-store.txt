notes
-----
- `effective_status` owns expiry; both stores derive list/active from it.
- File add uses temp file + os.link, decide/cancel rewrite with os.replace under
  a process lock. Postgres decide/cancel is a conditional UPDATE with RETURNING.
- Bandit B608 on the earlier f-string column list was avoided by inlining the
  column lists into constant SQL.
- The ADR's 7-day maximum expiry and the retired-version rejection are not in
  this store; they belong in the API layer (SLICE-080) and the loader/runtime.
