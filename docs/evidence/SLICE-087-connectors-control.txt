notes
-----
- The red probes ran against a detached worktree at 4e1ceca with PYTHONPATH
  pointing at that tree's src; the editable venv install otherwise resolves to
  the working tree.
- `pg-8758ae83` is a global connector left by the SLICE-085 live check. It
  proves the list merges global and tenant records for a tenant caller.
- Audit events use the caller tenant and target `<tenant>/<id>`. Static token
  mode has no roles, so the token holder may write; the OIDC non-admin 403 path
  is covered by `test_non_admin_forbidden`.
- The console reaches the same Postgres rows through `HttpConnectorStore`, so
  the panel and the CLI share one store and one audit file.
