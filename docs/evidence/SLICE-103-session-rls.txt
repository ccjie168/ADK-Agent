notes
-----
- The tenant is read from the authenticated principal (request contextvar,
  falling back to current_invocation().principal.tenant), never from the
  user_id argument. A mismatched user_id yields zero rows.
- SQLAlchemy 2.1 has no ConnectionEvents.after_begin; the hook is the
  sync_engine begin event. A standalone SQLite run confirmed begin can execute
  SQL, and the Postgres tests confirm the setting reaches the transaction.
- serve-many previously built a runner factory only when --session-db was set,
  so a bare SESSION_URL was ignored there. The condition now includes
  SESSION_URL; this slice needs it because --session-rls requires SESSION_URL.
- tests/runtime/test_quota_rls.py imported asyncpg unconditionally. The dev
  environment does not declare the driver, so the module now skips when it is
  absent instead of failing collection. No assertion changed.
- app_states is not covered; tenant-sensitive application state must not be
  stored there.
- The database role must own the three tables, must not be superuser, and must
  not have BYPASSRLS. The live tests create a role with those properties.
