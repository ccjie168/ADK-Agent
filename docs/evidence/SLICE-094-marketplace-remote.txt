notes
-----
- Local entries keep every prior field and gain `source: "local"`; remote entries
  carry the `trust` block and none of the version, artifact or lifecycle fields.
- The combined sort is `(id, local-before-remote, version)`, so `crm-bot` sorts
  before `support-bot` here only because of the id.
- Review hardening added an explicit `unsafe_tenant` check before either source
  is read. Without it a remote-only console returned 200 with an empty list for
  `?tenant=../escape` while the contract promised 400.
- The `except Exception  # noqa: BLE001` around the lifecycle read is pre-existing
  and out of scope for this slice; comment review flagged it open rather than
  widening the change.
- The Registry panel shows a source badge, a trust badge (plus a disabled marker)
  and a Refresh selected control that calls `/api/remote-agents/{id}/refresh`.
  Open chat refuses remote rows before the load request is made.
