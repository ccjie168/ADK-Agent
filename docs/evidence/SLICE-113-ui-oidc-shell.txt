三、浏览器端到端
1. 登录页
   GET /auth/config -> {"enabled":true,"client_id":"console","authorization_endpoint":"http://127.0.0.1:9000/authorize","redirect_uri":"http://127.0.0.1:8083/auth/callback","scopes":["openid","profile","email"]}
   OIDC 按钮可见，手工 token 行隐藏；页面无 JS 异常。
2. PKCE 跳转（mock IdP 日志）
   GET /authorize?response_type=code&client_id=console&redirect_uri=http%3A%2F%2F127.0.0.1%3A8083%2Fauth%2Fcallback&scope=openid+profile+email&state=2NoQ5yEXtTEgVuYefXgQow&code_challenge=De6tjSBSQXOUX4nVqubLmUVVMave2OpSDgUzoe6lS5A&code_challenge_method=S256 -> 302
   POST /token -> 200（服务端校验 S256(verifier) 与 code_challenge 一致）
3. 回调后
   path=/，app 显示、login 隐藏，token 长度 613，agents=[bot_a, bot_b]，registry rows=2
   GET /api/agents 200，GET /api/tenants 200，GET /api/registry?tenant=acme 200，GET /api/runs 200，GET /api/plans 200，GET /api/audit 200
4. state 不匹配
   访问 /auth/callback?code=abc&state=wrong -> 停留在登录页，文案“登录状态不匹配，请重试”
5. 退出
   path=/，login 显示，sessionStorage 中 adk_token 已清空
6. 布局
   1440x900: 左侧导航宽 220px，主区 1220px；深色主题切换后背景与面板变量生效
   755px（媒体查询生效）: 顶栏换行，导航变为顶部换行布局，无横向溢出
