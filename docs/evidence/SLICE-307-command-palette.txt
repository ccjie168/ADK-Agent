用例映射：

- `test_nav_source_is_shared`：`nav.ts` 的 27 个内部路由都在 router 里、能力名都在
  `capabilities.ts` 里，`/guide` 标为外部链接；`nav.ts` 的内部路由集合与 `App.vue`
  侧边栏的 27 个 `to` 完全相等，改一边漏另一边会红
- `test_palette_filters_by_capability`：面板读 `NAV_GROUPS`、按 `capabilities` 与
  `hasCapability` 过滤、跳过 `external`、无 `v-html`
- `test_palette_keyboard_and_a11y`：`role="dialog"`、`aria-modal`、`aria-activedescendant`、
  方向键/Enter/Esc、`nextTick` + `focus()`
- `test_palette_shortcut_is_wired`：`Ctrl`/`⌘` + `k`，挂载与卸载监听
- `test_palette_is_built`：`web/dist` 里含「命令面板」「跳转到页面」
- `test_guide_documents_the_palette`：手册记录 Ctrl/⌘、Esc

三、实机（headless Edge + CDP，本机 8031）

控制台用 `--ui vue --role admin --auth-token-env ADK_MCP_AUTH_TOKEN` 起在
`127.0.0.1:8031`，浏览器把 token 写进 `sessionStorage` 后重载：

    NAV: 28                      # 侧边栏条目（27 个内部页面 + 使用说明）
    OPTIONS: 27                  # 面板不列外部链接
    FILTERED: 审计 /audit         # 输入「审计」只剩一条
    HASH: #/audit                # Enter 跳转
    CLOSED: True                 # 跳转后自动关闭

截图：`docs/evidence/ui/SLICE-307-palette.png`（全量列表）与
`docs/evidence/ui/SLICE-307-palette-filter.png`（过滤后）。

焦点行为（同一 headless Edge 会话说）：

    FOCUS_IN_INPUT: palette-input     # 打开后焦点在输入框
    AFTER_TAB: palette-input          # Tab 不逃出对话框
    RESTORED: theme-toggle            # Esc 关闭后焦点回到打开前的元素

六、限制

- 面板只跳转页面，不搜索 Agent、运行、审批等对象（需要新查询接口）。
- 触屏没有手势入口，`Ctrl+K` 不适用；侧边栏保持原样。
- 面板隐藏入口只是界面行为，服务端授权不变。
