SLICE-167 风险分级类型 RiskLevel
日期: 2026-11-19
依据: ADR-0029（Accepted 2026-11-19）决定 1
基线: c5975b2

一、实现

- `core/policy.py` 新增 `RiskLevel = Literal["L1", "L2", "L3", "L4"]`，`ToolGrant` 增加可选字段
  `risk_level: RiskLevel | None = None`（向后兼容旧记录）。
- `core/__init__.py` 导出 `RiskLevel`。
- 重生成 `docs/contracts/tool_gateway_request.schema.json` 与 `manifest.schema.json`（内嵌 ToolGrant
  带 risk_level enum）。
- 新增 `tests/test_risk_level.py` 三个测试。

二、绿态

$ python scripts/check.py --fast
1675 passed, 90 skipped（ALL PASS，7 步）

$ python scripts/check.py --full
ALL PASS（9 步，含 bandit / pip-audit）

三、红态

基线 c5975b2 上 `ToolGrant` 无 `risk_level` 字段：`test_tool_grant_accepts_risk_level` 与
`test_tool_grant_risk_level_defaults_none` 在基线失败（`AttributeError: 'ToolGrant' object has no
attribute 'risk_level'`）。`test_tool_grant_rejects_unknown_risk_level` 在基线因 `extra="forbid"`
已绿（非法字段被拒），实现后由 Literal 约束继续拒绝非法值。

四、范围与已知缺口

- `ToolEntry`/`PlanStep`/`ConnectorSpec` 的 risk_level（ADR-0029 slice 2）。
- `PlanExecutor` 审批门按 risk_level 驱动（slice 3）。
- L4 默认拒绝（slice 4）。
- ADR-0034 写工具幂等（Gate 4 另一半）。
