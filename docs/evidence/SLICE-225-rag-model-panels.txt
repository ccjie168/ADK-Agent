SLICE-225 RAG 面板 + 模型网关面板
日期: 2026-11-22
依据: ADR-0039 MVP 第 4 项（构建能力补全：RAG 面板 + 模型网关面板）
基线: `f58ec0e`

一、契约

- `docs/contracts/console.md` 补 `GET /api/rag` 与 `GET /api/model` 两节，写明「最近 200 条审计
  事件的窗口摘要」语义。

二、实现

- `console.py` 新增 `GET /api/rag`：统计 `rag.retrieve` 条数与最近一次 `rag_top_k`/`rag_returned`。
- `console.py` 新增 `GET /api/model`：统计 `model.call` 条数、去重的 `model_alias` 集合与
  `fallback_count` 总和。
- 新增 RAG 面板 `section#rag` 与模型面板 `section#model`（`.stat-card` 展示），导航「构建」组加
  RAG / Model tab，`loadRag`/`loadModel` 在登录后拉取。
- `scripts/prove_it_works.py` 的 `check_console_ui`（P13）额外断言 `id="rag"`/`id="model"` 与
  `/api/rag`/`/api/model` 端点返回 `recent_retrievals`/`recent_calls` 字段。

五、范围与已知缺口

- RAG 面板不查语料/分块数的存储级统计（需 `PgVectorRagStore` 计数方法，另开切片）。
- 模型面板不展示实时熔断/预算余额（在独立 `serve-model-gateway` 进程里，console 不直连）。
- 语义层面板从 SLICE-226 起。
