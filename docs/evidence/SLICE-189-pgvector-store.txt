一、实现

- `rag/vector_store.py` 新增 `RagChunk`（tenant/source_id/chunk_id/text/embedding/data_classes/
  allowed_subjects）、`RagChunkRow`、`RagStoreUnavailable` 与 `PgVectorRagStore`。
- 建表：`CREATE EXTENSION IF NOT EXISTS vector` 与 `adk_rag_chunks`（主键
  `(tenant, source_id, chunk_id)`，`embedding vector(N)`，`data_classes text[]`，`allowed_subjects
  text[]`），`ENABLE`/`FORCE ROW LEVEL SECURITY`，策略 `tenant = current_setting('app.tenant_id', true)`。
- `upsert` 覆盖写入；`search` 在事务内设置 `app.tenant_id`，按租户、`data_classes <@ 请求集合`、
  `allowed_subjects` 过滤后按余弦距离 `<=>` 排序限量返回。
- 维度校验：`validate` 与 `search` 在维度不符时抛 `RagStoreUnavailable`；扩展缺失或 SQL 失败同样
  fail-closed。
- 新增 `tests/test_pgvector_store.py` 五个测试（四个 live 用例需 `TEST_POSTGRES_URL`）。
