SLICE-152 凭据审计版本号的共享与安全化
日期: 2026-11-19
依据: SLICE-151 验证代理的信息级发现
基线: 56d2045

一、实现

- `core.credentials.credential_version()`：空值 `credential`；安全字符集 `credential.<key id>`；
  否则 `credential.<sha256 前 12 位>`。
- `TenantSecretProvider` 与注册表服务共用该函数，删除 providers 内的重复正则。
- 控制面 `credential.register|disable` 审计改用共享函数，不安全 key id 不再触发 `ValidationError`。
- `docs/contracts/registry_service.md` 补上注册/停用审计 version 的哈希回退规则。

二、绿态

$ pytest tests/test_credentials.py tests/registry/test_credential_service.py -q

$ pytest -q（Windows）

$ python scripts/check.py --full

三、红态

基线控制面直接拼接 `credential.<key id>`，key id 为 `prod/key` 时 `AgentRef` 校验失败；
providers 自有一份安全字符集正则，与注册表的拼接逻辑分叉。

四、范围与已知缺口

- 控制台注册审计的 version 固定为 `credential`，与 key id 无关。
- 运行时审计主体归因（工具网关/控制台没有 invocation）仍是信息级缺口。
