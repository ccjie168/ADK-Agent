notes
-----
- The console registers the runner and runtime only after the artifact loads
  and verifies, so a failed load leaves the agent set unchanged.
- Loaded versions are tracked per name; loading another version of a loaded
  name returns 409 name_conflict instead of swapping the running agent.
- AuditEvent requires tenant == principal.tenant, so the agent.load event is
  recorded under the caller's tenant even when an admin loads another tenant's
  version. The target tenant is visible on the registry record itself.
