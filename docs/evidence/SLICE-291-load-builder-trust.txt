红灯原因是新参数在 master 上不存在（TypeError: load_agent() got an unexpected keyword
argument 'builder_keys' / build_console_app 的 builder_keys），唯一通过的是
test_serve_accepts_builder_keys：master 本来就不设防，所以「带信任集能载入」在旧代码上也成立。

二、行为证明：master 真的执行了没有构建签名的 in_process 工件

探针脚本在临时目录手工构造一条文件注册表记录：发布签名合法（publisher-1），
builder_signature / builder_key_id 为空，execution_tier=in_process。

master 源（PYTHONPATH 指向 git archive 出来的 master src）：

    $ PYTHONPATH=<temp>/master/src python probe.py <temp>/master-run
    builders: parameter absent (load_agent() got an unexpected keyword argument 'builder_keys')
    loaded: bot

分支源（当前工作区）：

    $ python probe.py <temp>/branch-run
    Traceback (most recent call last):
      File "src\adk_agent\registry\loader.py", line 162, in load_agent
        raise ArtifactLoadError(
          "in_process artifacts require builder trust: "
          "provide --builder-keys or set ADK_BUILDER_KEYS"
    adk_agent.registry.loader.ArtifactLoadError: in_process artifacts require builder trust: provide --builder-keys or set ADK_BUILDER_KEYS

即：旧代码把未经构建签名的 in_process 工件载入并执行；新代码在执行前拒绝。
