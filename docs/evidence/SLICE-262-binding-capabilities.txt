## 实现（后绿）

- console.py：新增 `_effective_roles(caller)` = `caller.roles ∪ 该租户绑定角色`；绑定按 `caller.tenant` 查，
  请求参数无法指定租户；`UserBindingStoreError`/`ValueError` 时记日志并**只用 token 角色**继续解析。
  `_caps_for` 改用有效角色集，其余逻辑（未定义角色空集、空则基础能力、role store 失败 fail-closed）不变。
- docs/contracts/console.md：能力来源一节补「有效角色 = token ∪ 租户绑定」、并集只加不减、
  绑定故障保留 token 角色。
