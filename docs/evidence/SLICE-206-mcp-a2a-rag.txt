日期: 2026-11-21

基线: `b49a85e`

一、契约

- 先改 `docs/contracts/cli.md`：新增「`serve` / `serve-many` / `serve-a2a` 的运行时检索（ADR-0036）」
  一节，写明 `--rag-*`、只对注册表记录生效、`rag.retrieve` 审计与 `on_error` 语义。
- manifest 与审计事件形状不变。

二、实现

- `src/adk_agent/runtime/audit_proxy.py`：`AuditedRunner` 与 `wrap_runner` 接受 `rag`；运行前调用
  `RagContext.prefix(invocation)`，把返回的固定边界块作为首条文本 part 拼到 `new_message` 前；
  检索异常走既有 audited try，写 `agent.run` error 后重新抛出。
- `src/adk_agent/a2a.py`：`build_a2a_app`/`serve_a2a` 接受并透传 `rag` 给 `wrap_runner`。
- `src/adk_agent/mcp/server.py`：`serve_agent`/`serve_many` 接受 `rag`/`rag_for`，按工具取上下文传给
  `wrap_runner`；只给 rag 也会包一层审计代理。
- `src/adk_agent/cli.py`：`serve`、`serve-many`、`serve-a2a` 增加 `--rag-db/--rag-dimensions/--rag-model/
  --rag-provider`；新增 `_agent_rag(factory, agent)`，从注册表加载附加的 `_adk_manifest` 构造上下文，
  文件加载的 agent 没有 manifest 返回 `None`；`serve-many` 复用同一个 factory。
- 运维与使用手册更正：MCP 与 A2A 已接线，文件加载不检索。
