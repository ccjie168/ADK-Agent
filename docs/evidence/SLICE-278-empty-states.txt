SLICE-278 空态、表格滚动与令牌化收口 — 证据
==========================================

日期: 2026-11-24
分支: slice-278-empty-states
依据: ADR-0041；Cloudflare 风格视觉改造

## 反例（先红）

实现前运行新增用例:

    python -m pytest tests/test_console_vue_polish.py -q
    5 failed

失败项：六个列表页没有 `EmptyState`；表格没有 `.table-wrap`；`.stat-value-text`、`.toolbar`
不存在；徽章仍是旧绿 `#e6f5ea`。

## 实现（后绿）

- **空态**：运行、计划、工具三个 `v-else` 表格页改为「错误 → 空态 → 表格」三分支；
  会话与对端在各自区块内加 `EmptyState`（会话与错误串联，对端与提示并列）；
  审计页的「暂无审计事件」换成 `EmptyState`。
- **窄屏表格**：上述五个表格页把 `<table>` 包进 `.table-wrap`（`overflow-x: auto`），
  空行从 `<tbody>` 里移除。
- **指标字号**：首页「未配置」用 `.stat-value-text`（16px、`--text-muted`），数字仍是 28px。
- **表单工具条**：Agent 中心租户输入与按钮收进 `.toolbar`（最大 520px）。
- **徽章令牌化**：`.badge` / `.expiry` 的成功、警告、危险配色改用
  `--success-*`、`--warning-*`、`--danger-*` 与 `--card-muted`。
