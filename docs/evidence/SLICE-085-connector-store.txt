notes
-----
- `ConnectorSpec` rejects embedded URL credentials, non-loopback http, path
  prefixes with `..`, empty methods, and timeouts outside 1..60s or responses
  over 8 MiB.
- Only `secret://` references are accepted for auth_ref.
- File add uses os.link; Postgres uses INSERT ON CONFLICT DO NOTHING plus a
  definition compare that ignores `enabled`, so a disabled connector stays
  disabled and re-registering the same definition is idempotent.
- Bandit B105 flagged the constant name `_SECRET_REF` with a regex value; it is
  now `_AUTH_REFERENCE`.
