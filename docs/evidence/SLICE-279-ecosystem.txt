## 实现（后绿）

- `web/src/views/EcosystemView.vue`（`/ecosystem`，导航「开发」组，内联 `network` 图标）：
  - 工具目录读 `/api/tools`（`tools.read`）、连接器读 `/api/connectors`（`connectors.read`）、
    A2A 对端读 `/api/peers`（`peers.read`）；只有三项都无权时整页「无访问权限」。
  - 计数卡：工具、MCP 工具、连接器、A2A 对端；无权项显示「—」。
  - 接入引导三张卡：登记 `--kind mcp` 连接器、`serve --transport streamable-http`、
    `peers register`；命令可复制（`navigator.clipboard`，失败给固定提示）并链接到对应页面。
  - 工具表按来源筛选（全部 / MCP / 连接器 / 函数 / OpenAPI）；空态用 `EmptyState`。
  - 连接器表标出 MCP 服务器数量；对端表显示授权数。
- `web/src/router/index.ts`、`web/src/App.vue`、`NavIcon.vue`、`style.css` 增加路由、入口、
  图标与引导/筛选样式。
- 已把它纳入共享的页头测试与外壳导航测试。
