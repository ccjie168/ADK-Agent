说明
----
- 包名是 adk_agent.secretstore，避开仓库的 secrets/ 读取禁区。
- EnvSecretProvider 只读环境变量。引用必须是环境变量名。
- MappingSecretProvider 用于测试和注入。
- 密钥值含 CR/LF 时拒绝，防头部注入。
- 错误只写引用名，不写密钥值。
- McpServerConfig.header_secrets 只允许 http。headers 和 header_secrets 不能同名。
- 配置里只存密钥引用，引用格式是环境变量名，字面密钥会被拒绝。
- MCP 和 OpenAPI 的认证头通过 header_provider 在请求时解析。
- OpenAPI 只接受 JSON 对象。ADK 默认拒绝私网、回环和云元数据地址。
- build_agent 默认用 EnvSecretProvider，并传给子 agent。
- 控制台按 OpenAPI 工具名和 MCP tool_filter 发 grant。没有工具列表时 fail closed。
- framework_config.schema.json 已重新生成，契约同步测试通过。
- MCP 测试放在 tests/test_mcp_client.py，避免 tests/mcp 目录把 mcp 包误判成 first-party。
- lint 步骤加 --no-cache。旧缓存曾让本地 lint 通过而 CI 失败。
