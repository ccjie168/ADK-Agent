== reading ==
- The loader re-hashes the bytes against the declared digest before touching the zip, even though
  the store already verified on write.
- Entries are read, not extracted: path traversal, absolute paths, symlinks, duplicate names,
  unexpected files, oversized expansion and too many entries are rejected before any code runs.
- Trust is checked before load_agent calls the loader. An unknown key id or a bad signature stops
  the run; there is no unsigned fallback.
- Executing the module is the intended trust boundary of ADR-0008. It runs in-process with the
  platform's privileges, not in a sandbox.
