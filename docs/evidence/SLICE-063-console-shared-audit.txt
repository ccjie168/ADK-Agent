== reading ==
- The console no longer owns a second history. With --audit-url, every replica reads the same
  events; the process buffer is only the no-flag fallback.
- Reads are tenant-scoped by the console principal and enforced again by the audit service.
- A dead audit service fails the panels closed with a fixed 502; it does not fall back to stale
  local data.
- Writes and reads both depend on the service. If it is down, the panels return 502 and the run
  write path raises AuditSinkUnavailable, so the chat also fails; there is no local fallback.
