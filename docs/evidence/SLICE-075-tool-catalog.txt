live, real console with a file registry and a catalog file
----------------------------------------------------------
Registry contains `acme/support-bot@1.0.0` with tool_grants for crm.read and
crm.export. Catalog has a global crm.read, an acme-only crm.export, and an
other-tenant billing.read. Console on 8808 with `--registry`, `--tool-catalog`.

  {"tool_id": "crm.read", "source": "function", "data_classes": ["internal"],

billing.read (tenant=other) is filtered out.

Screenshot: docs/evidence/ui/SLICE-075-tools.png shows the Tools tab with the
two acme-visible tools, their source, data class, approval flag and grants.

notes
-----
- The catalog is a plain file so it can describe function, OpenAPI, MCP and
  connector tools before those sources have a shared discovery API.
- Grants come only from published manifests; the console never infers them.
- A missing registry yields empty grants instead of an error; a broken registry
  returns 500 registry_corrupt.
