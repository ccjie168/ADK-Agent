SLICE-224 审计面板 + 配额面板
日期: 2026-11-22
依据: ADR-0039 MVP 第 3 项（治理能力补全：审计面板 + 配额面板）
基线: `8ad77bc`

一、契约

- `docs/contracts/console.md` 补 `GET /api/overview`（SLICE-223 遗漏）与 `GET /api/quota` 两节。
- `QuotaManager`（`core/ports.py`）端口新增 `usage(tenant, policy) -> QuotaUsage`；`QuotaUsage` 随
  `core/quota.py` 导出（`window_runs`/`active_leases`/`max_runs`/`max_concurrent`/`window_seconds`）。

二、实现

- `core/quota.py`：新增 `QuotaUsage`（冻结、`window_runs`/`active_leases` 非负、`window_seconds` 正）。
- `core/ports.py`：`QuotaManager` 协议加 `async def usage(...)`。
- `runtime/quota.py`：`InMemoryQuotaManager.usage` 清理过期窗口后返回运行数/活跃并发/策略。
- `runtime/quota_postgres.py`：`PostgresQuotaManager.usage` 设 `app.tenant_id`（RLS）、清理过期运行与
  租约后 `count(*)` 返回；失败映射 `QuotaStoreUnavailable`。
- `console.py`：新增 `GET /api/quota`（未配置或租户不在配置里 404 `quota_not_configured`，后端不可用
  503 `quota_unavailable`）；新增审计面板 `section#audit-panel` 与配额面板 `section#quota`，导航「治理」
  组加 Audit / Quota tab；`loadAuditPanel`/`loadQuota` 渲染，登录后与租户切换时拉取。
- `scripts/prove_it_works.py`：`check_console_ui`（P13）额外断言 `id="audit-panel"` 与 `id="quota"`。
