== reading ==
- Rotation is additive: add the new key, point active at it, keep the old key, and set
  legacy while history without a kid remains. Nothing is re-signed.
- Removing a key too early fails closed at the first record that used it.
- Error messages stay constant and never interpolate key material or kid values.
- The record schema gained one optional field; the chain hash does not cover kid, so the
  hash chain of existing records is untouched.
