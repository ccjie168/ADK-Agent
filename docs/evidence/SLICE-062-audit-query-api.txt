== reading ==
- The read path uses the same file the writer owns. A query reads all segments and filters
  in memory, so cost grows with retained history; limit caps the response, not the scan.
  Paging or a database backend is the next step if history grows.
- OIDC binds queries to the token tenant; admin can cross tenants. Static-token deployments
  are treated as operators.
- Chain verification is unchanged and still lives in verify-audit; the query returns events,
  not proof.
