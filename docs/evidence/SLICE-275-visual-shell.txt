## 独立验证反馈修正

首轮验证判 **REJECT**（B1 + 5 个 S + 3 个 N），已全部修：

1. **B1（阻塞）**：`ready` 只覆盖「刷新时已带 token」。token 登录与 OIDC 回调时 `ready` 早已为真，
   `RouterView` 仍在 `/api/me` 之前挂载，落地页空白。现在新增 `resolved`，三条登录路径都在
   `fetchMe` 前把它置 false、结束后置 true；`App.vue` 以 `!auth.resolved` 作为挂载条件。
   新增 `test_auth_store_holds_the_shell_for_every_login_path`（断言置位顺序）。
2. **S1**：`/api/me` 401 只清 sessionStorage，store 仍认为已登录。现在 401 同时清空
   `token`/`principal`/`capabilities`；新增 `test_auth_store_clears_a_rejected_token`。
3. **S2**：`/api/me` 网络异常变成未处理 rejection。现在 `fetchMe` 捕获并写 `meError`，
   外壳顶部显示固定提示，不再抛到 `init` 之外。
4. **S3/S4**：旧硬编码灰字（`#64748b`/`#94a3b8`）在白色表面上低于 AA，分组标签 3.15:1。
   现在统一用 `--text-muted`（`#52525b`）与 `--text-subtle`（`#6b6b73`），并新增
   `test_tokens_meet_text_contrast` 对四组前景/背景做 4.5:1 断言。
5. **S5**：证据把导航写成 28 项、旧导航 9 项，实际是 25 / 10，已更正。
6. **N1**：移动开关补 `aria-expanded`、`aria-controls` 与随状态变化的标签。
7. **N2**：旧 `.login { max-width: 360px }` 覆盖了新宽度，已在新块里置 `max-width: none`。
8. **N3**：补三条测试（登录路径、401、对比度），并让导航用例覆盖全部 25 条路由。
