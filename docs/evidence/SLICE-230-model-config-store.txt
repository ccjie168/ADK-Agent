SLICE-230 模型配置类型与 store
日期: 2026-11-22
依据: ADR-0040 MVP 第 1 项（配置类型 + store + override 优先级）
基线: `c469261`

一、契约

无对外接口变更。`ModelConfigStore` 是框架内部端口，`/api/model-config` 属 SLICE-231。

二、实现

- `models/config_store.py`：`ModelConfigStore` 协议（`get` / `put`）与 `ModelConfigStoreUnavailable`。
- `registry/model_config.py`：`FileModelConfigStore`（`<root>/model.txt`，tempfile fsync + os.replace 原子写）。
- `registry/model_config_postgres.py`：`PostgresModelConfigStore`（`adk_model_config` 单行，`ON CONFLICT DO UPDATE`，
  `LazyPool` / `normalize_dsn`）。
- `models/__init__.py`：模块级 `_default_model_override` + `set_default_model(spec)`；
  `_default_model_config()` 读 override 优先于 `ADK_AGENT_MODEL` 与 fallback（优先级 2/3/4）。
