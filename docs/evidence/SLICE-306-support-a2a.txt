  `SupportFlowAgent`，测试线程批准后 A2A 回复含 `t-1`，mock 工单为 open，微信有通知

五、过程中发现并修复的平台缺陷

`serve-a2a --agent <自定义 BaseAgent>` 在 `install_declared_guards` 处退出：

    AttributeError: 'SupportFlowAgent' object has no attribute 'before_tool_callback'

`install_tool_guard` 原先直接读三个回调属性。现在用 `hasattr` 判断，未声明的自定义
agent 跳过，`sub_agents` 递归不变；`LlmAgent` 行为不变（原有 8 条守卫用例全过）。

七、限制

- A2A 调用是同步的：`message/send` 阻塞到审批完成或超时（服务端 `wait + 60` 秒），
  真实 WorkBuddy 需要设置客户端超时。
- 拒绝与超时都返回 200 + 一段文本（HTTP 错误码区分不了「机器错误」与「人拒绝」），
  客户端脚本按文本判断。
- `ticket_writer` 直接走 HTTP 调 mock，不经过工具网关；连接器只登记未执行。
