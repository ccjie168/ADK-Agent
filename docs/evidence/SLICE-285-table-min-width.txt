SLICE-285 表格容器的窄屏最小宽度 — 证据
========================================

日期: 2026-11-25
分支: slice-285-table-min-width
依据: PROGRESS 控制台视觉残余（`.table-wrap` 无可滚动的最小宽度）

## 反例（先红）

    python -m pytest tests/test_console_vue_tables.py -q
    1 failed, 1 passed

失败项：`style.css` 没有 `.table-wrap table` 规则。另一条视图仍使用 `.table-wrap` 的用例
在旧代码上通过，作为回归保护。

## 实现（后绿）

    .table-wrap table {
      min-width: 720px;
    }

只改 `web/src/style.css`；`web/dist/` 重建。

    python -m pytest tests/test_console_vue_tables.py -q
    2 passed

    cd web && npm run build
