notes
-----
- PyPI and Debian mirrors were used for generation and the local build because
  the default indexes were unreachable from this network. The lock files carry
  no index URL (--no-emit-index-url), and build args are not persisted in the
  image. The hashes are what is verified.
- `--only-binary :all:` is used in the image install. All 91 runtime pins have
  a Linux wheel, confirmed by the reproducible download above.
- Residual gap: the project itself is built with build isolation, so hatchling
  is fetched from the index at build time without a hash. Closing it means
  adding a build extra to both locks and using --no-build-isolation; that is
  follow-up work, not claimed here.
- CI builds and scans the image but does not push it, so it cannot emit the
  final digest. The manifests use an all-zero digest placeholder and the
  runbook says to replace it with the pushed digest.
- The Trivy GitHub Action is pinned by version (0.28.0), not by commit SHA.
  SHA pinning is a follow-up.
