1. 快速开始与登录

控制台是一个网页，默认只监听本机回环地址。打开地址后先登录，再看到左侧导航。

  • token 模式：登录页输入运维发给你的 Bearer token。token 只存在当前浏览器，退出即清除。
  • 单点登录：配置了 OIDC 时显示「使用单点登录」，跳转企业身份提供方后回到控制台。

登录后右上角显示租户与主体名。左侧导航只显示你有能力访问的入口；看不到某个页面通常意味着当前角色缺少对应能力，而不是页面坏了。

2. 键盘与命令面板

按 Ctrl+K（macOS 上 ⌘+K）打开命令面板，输入页面名或路径即可过滤：

  • ↑ / ↓ 选择，Enter 跳转，Esc 或点遮罩关闭；
  • 面板与左侧导航用同一份数据，只列出当前角色有能力的入口；「使用说明」这类外部链接不在面板里；
  • 切换主题按钮仍在右上角；命令面板不改变任何权限判断，服务端授权照旧。

4. 概览

总览 /

平台运行概况与常用入口：待审批、已注册 Agent、工具与授权数量，以及最近活动。

前提：需要 ops.read 或 registry.read。操作：点统计卡进入对应页面。

5. 运行

运行 /runs

每一轮对话或触发的执行记录，含状态、耗时、租户与 trace。

前提：runs.read。操作：按租户与状态筛选，点进详情看事件与审计。

计划 /plans

多步计划的执行情况，需要人工确认的步骤会停在这里等待审批。

前提：runs.read（审批操作需 approvals.decide）。

会话 /sessions

共享会话列表，用于恢复上下文或排查异常对话。

前提：sessions.read。

审批 /approvals

需要人工确认的工具调用与计划步骤。批准或拒绝时要填写理由，决定会写入审计。

前提：approvals.read；决定需要 approvals.decide。未配置审批存储时页面会提示用 --approval-dir 或 --approval-db 启用。

聊天 /chat

与已加载的 Agent 对话。选择下拉里的 Agent，输入消息后发送；回复与审计同步产生。

前提：chat.run，且至少有一个已加载的 Agent。

Ask AI /ask-ai

用术语表做确定性路由回放：输入问题，看命中的概念与建议入口。

前提：runs.read；术语表为空时先到「语义层」导入。

6. 治理

访问控制

策略 /policy

访问策略与绑定：工具调用的风险分级、审批阈值与租户规则。

前提：policy.read；编辑需要 policy.write。未配置时提示用 --policy 指定文件。

角色 /roles

角色定义决定能力集合。内置角色在启动时自动补齐；自定义角色在下方表单新增。

前提：roles.read；写需要 roles.manage。未配置角色存储时提示用 --role-store-dir 或 --role-store-db。

用户 /users

把登录主体绑定到角色。绑定只做加法，不会削减 token 自带角色。

前提：roles.read；写需要 roles.manage。

授权 /grants

工具临时授权请求与到期时间。运行时申请放行的工具调用会出现在这里。

前提：grants.read；决定需要 grants.decide。

审计与合规

审计 /audit

共享审计事件：运行、工具调用、配置变更与登录。每条事件带 tenant、principal 与哈希链。

前提：audit.read，以及审计后端（--audit-file、--audit-db 或审计服务）。

安全 /security

审计、密钥、策略与扫描的聚合视图。未接入扫描或安全摘要时显示配置提示。

前提：ops.read。

集成与配额

工具 /tools

工具目录与授权关系：每个工具的风险级别、数据类别与可调用角色。

前提：tools.read；目录来自 --tool-catalog 或注册表。

连接器 /connectors

外部 API 的访问方式：ID、租户、类型、Base URL、方法与启用状态。下方表单可直接登记。

前提：connectors.read；登记与停用需要 connectors.manage。未配置时提示 --connectors-dir。

凭据 /credentials

租户凭据只保存引用（secret://...），密钥值由服务端环境提供，不进入浏览器。

前提：connectors.read；写需要 connectors.manage。未配置时提示 --credentials-dir 或 --credential-db。

对端 /peers

A2A 对端身份与动作授权：允许哪个对端调用哪个 Agent。

前提：peers.read；写需要 peers.manage。登记用 adk-agent peers register。

语义层 /semantics

术语表与概念：Ask AI 与检索复用这里的定义。

前提：ops.read；导入用「导入」页或 CLI。

检索 /rag

检索调用与返回统计：最近 top_k、命中数与延迟。

前提：ops.read，并配置 --rag-db 与模型。

配额 /quota

租户配额用量与限制：运行次数、令牌与时间窗口。

前提：ops.read；配额来自 --quota-config，未配置时不受限。

7. 开发

Agent 中心 /agents

注册、版本与生命周期。卡片展示每个 Agent 的版本与状态，可进入注册表或新建。

前提：registry.read；「新建」需要 registry.publish 或 registry.compose。

新建 Agent /agents/new

四步向导：选模板、填参数、预览生成的 manifest 与 agent.py、发布。

前提：预览需要 registry.publish；发布需要 registry.compose 且控制台配置了四个 compose 密钥。未配置时页面给出等价的 CLI 命令。

注册表 /registry

已发布版本与远端目录：查看版本、生命周期状态，把版本加载成聊天目标。

前提：registry.read；加载需要 registry.load。

模型 /model

调用、别名、默认模型与模型提供方。切换默认模型后，新会话生效。

「模型提供方」列出 --model-providers-dir 下的记录：类型、模型、端点与密钥状态。 admin 可以在下方表单按 provider_id 创建或更新；kind 取 litellm、gemini、claude、vertex， 密钥引用用 secret://tenant/name，也可以留空。

开启 --model-key-entry 时，每行可以只写保存 API Key：平台用 KEK 加密保存， 页面只显示掩码（如 sk-…abcd），可随时吊销；没有配置 KEK 时保存会提示 「密钥后端不可用」。保存的密钥优先于 secret:// 引用，两者都会覆盖环境变量。

运行时解析顺序：启用记录 > 环境变量 > 内置默认；记录只补密钥与端点，不改变模型名。 服务命令同样接受 --model-providers-dir。

前提：model.read；写入记录与密钥需要 model.write。

生态 /ecosystem

MCP、A2A、连接器与可复用工具的总览，按来源分组查看。

前提：tools.read、connectors.read、peers.read 任一。

导入 /import

导入术语表或 Agent 清单。清单导入只登记 manifest，不带工件字节。

前提：runs.read；写入需要 registry.publish 或 semantics.write。

8. 设置

设置 /settings

控制台自身的偏好页（当前是占位页）。侧栏「设置」组里的「使用说明」另开页面展示这份手册。

主题：顶栏右侧的「深色／浅色」按钮切换主题，选择记在浏览器里；第一次访问跟随系统偏好， 登录页也可以切换。深色主题覆盖全部页面与手机布局。

对所有登录主体可见。

9. 两条完整流程

把已有 Agent 跑起来

  1. 在「注册表」找到目标版本，确认生命周期不是 retired。
  2. 点「加载」，控制台在进程内或沙箱里载入工件；载入失败会显示原因。
  3. 到「聊天」选择该 Agent，发一条消息。
  4. 到「运行」看这一轮的记录，再到「审计」确认 agent.run 事件。

从模板发布一个新 Agent

  1. 「新建 Agent」→ 选 single-llm 模板。
  2. 填名称、版本、租户、指令与工具，点「预览」检查 manifest 与代码。
  3. 确认无误后点「发布」；需要评测门禁时先在 CLI 跑 eval。
  4. 发布成功跳到注册表；在「授权」放行工具，在「配额」确认额度。
  5. 「审计」能看到 agent.compose 事件（不含指令原文）。

10. 常见错误与处理

界面提示含义处理
连接器存储不可用控制台没配置连接器存储启动加 --connectors-dir，或用注册表的连接器接口
审批存储未配置审批后端缺失加 --approval-dir 或 --approval-db
凭据存储不可用凭据后端缺失加 --credentials-dir 或 --credential-db
角色存储未配置角色定义存储缺失加 --role-store-dir 或 --role-store-db
用户绑定存储未配置用户绑定存储缺失加 --user-binding-store-dir 或 --user-binding-store-db
工具目录不可用没有工具目录加 --tool-catalog
授权存储不可用工具授权后端缺失加 --tool-grants-dir 或 GRANT_URL
检索统计不可用RAG 未配置加 --rag-db、--rag-dimensions 与 --rag-model
配额数据不可用没有配额配置加 --quota-config
无访问权限 / forbidden当前角色缺少能力：该页面或动作所需的能力不在你的角色里让管理员在「角色」或「用户」页授权；不要靠改前端绕开
artifact_untrusted / load_failed工件载入失败，常见于构建签名或发布签名不可信确认发布端与载入端使用同一套 --artifact-keys 与 --builder-keys
401 unauthorized没有令牌或令牌失效重新登录；token 模式重新输入 Bearer token
